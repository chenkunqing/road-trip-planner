# 旅途助手 (Road Trip Planner)

智能旅行攻略生成工具 —— 按时间线整合景点、导航、餐饮、住宿，一键输出完整行程文档。

## 功能特点

- 🗓️ **时间线驱动**：以"几点到几点做什么"为主轴，清晰呈现每日行程
- 🗺️ **导航即搜即用**：每个地点附带高德地图搜索关键词
- 🎫 **门票透明**：价格、是否需预约、能否自驾进入一目了然
- 🏨 **住宿推荐**：含搜索关键词、价格区间、特殊提醒
- 💰 **费用汇总**：自动生成预算表，人均清晰
- ⚠️ **避坑指南**：列出各地特有注意事项
- 🌧️ **应急方案**：天气/景点变化的备选方案

## 适用场景

- 自驾旅行规划
- 自由行行程安排
- 多日游攻略生成

## 使用方式

### 安装

```bash
hermes skills tap add chenkunqing/road-trip-planner
hermes skills install travel-itinerary
```

### 使用流程

**第1步：召唤技能**

```
用户：帮我做一个去西藏的旅行攻略
```

**第2步：信息收集**

助手会询问以下信息（请如实回答）：

| 信息 | 说明 |
|------|------|
| 目的地 | 去哪个城市/地区？ |
| 天数 | 玩几天？ |
| 人数 | 几个人？有没有老人小孩？ |
| 出行方式 | 自驾还是公共交通？ |
| 预算 | 人均预算大概多少？ |
| 偏好 | 喜欢自然风光还是人文历史？ |

**第3步：确认大纲**

助手会先给出行程大纲（每天住哪里、玩什么），确认后再细化。

**第4步：获取完整攻略**

完成！包含每日时间线、门票、导航、餐饮、住宿、费用汇总、出发清单等。

### 输出示例

- **完整版**：含时间线、门票、导航、住宿、费用汇总（默认）
- **精华版**：只列每天主要景点和住宿点
- **清单版**：纯景点+餐饮推荐列表，无时间线

可以告诉助手你需要哪种格式。

## 注意事项

- 请尽量提供准确的人数、出行方式等信息，攻略质量会更高
- 如果行程有变（天气、时间调整），可以随时让助手调整
- 长途自驾建议预留缓冲时间，避免赶路太累
