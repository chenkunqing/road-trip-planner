# 路线审查与路线图创建

## 路线审查（用户要求检查行程时）

当用户问"有没有走重复路"或"检查行程问题"时，按以下维度审查：

1. **重复路段检测**：标出所有原路返回的路段，区分"不可避免的死胡同路（如塔县G314）"和"可优化的回头路（如精河↔赛里木湖）"
2. **赶时间风险**：标出当天有硬性截止时间（航班/还车）的日子，检查buffer是否够（建议至少留1.5h）
3. **睡眠不足风险**：前一天晚到（>23:00入住）+第二天需长途驾驶=危险组合
4. **住宿可订性**：偏远小镇旺季住宿选择少，主动提醒提前预订+给备选方案
5. **不确定因素**：季节性道路（如独库公路开通时间）需准备Plan B
6. **加油/充电盲区**：连续100km+无加油站的路段要明确标注"出发前加满"

审查结果格式：按严重程度排序，⚠️⚠️最紧急 → ⚠️需注意 → 💡优化建议。每个问题给出具体解决方案，不要只提问题不给答案。

## 路线图创建（用户要求路线图时）

当用户已经有详细攻略但需要"路线图"或"每天路线图"时，创建简化的路线可视化：

### 路线图包含要素
1. **总览表**：日期、星期、起点（前一晚酒店）、终点（当晚酒店）、主要路线、驾驶距离、驾驶时间、核心景点
2. **每日详细路线**：从前一晚住宿开始，到当晚住宿结束的完整路线
3. **路线流程图**：用ASCII箭头表示每天行程（起点→景点1→景点2→终点）
4. **空间路线概览**：整个行程的地理布局示意图（南疆段、北疆段分开画）
5. **租车信息**：分段租车取还车地点、时间、车型
6. **路线优化提示**：无重复路说明、加油盲区提醒、住宿提前订提醒

### 路线图格式
- 用Markdown表格展示总览
- 每日路线用ASCII流程图（`↓`箭头连接各点）
- 标注驾驶距离和时间（`↓ 约XXXkm / Xh`）
- 关键节点标注导航关键词（`📍导航关键词`）
- 重要提醒用⚠️标识（加油盲区、高海拔、无信号等）

### 与详细攻略的关系
- 路线图是详细攻略的**简化可视化版本**，不重复景点信息
- 详细攻略包含所有景点信息（门票、玩法、注意事项）
- 路线图只保留路线骨架和关键提醒
- 用户可以在路线图和详细攻略间快速切换参考

### 输出格式选择（根据用户需求）
1. **Markdown版本**（默认）：ASCII路线图 + 表格，适合聊天窗口直接显示
2. **HTML交互版本**：用户说"搞个HTML版本"或"可视化地图"时，创建基于Leaflet的交互式地图
3. **ASCII纯文本版本**：用于聊天窗口直接显示（当MEDIA附件发送失败时，直接输出内容）

## 服务器部署流程

当用户要求部署HTML地图到服务器时：

### 部署步骤
1. **创建项目目录**
   ```bash
   mkdir -p /home/ubuntu/{项目名}
   cp {HTML文件} /home/ubuntu/{项目名}/index.html
   ```

2. **启动HTTP服务器**
   ```bash
   # 使用Python内置HTTP服务器
   cd /home/ubuntu/{项目名}
   python3 -m http.server {端口} --bind 0.0.0.0 &
   ```

3. **检查服务器状态**
   ```bash
   netstat -tlnp | grep ":{端口}"
   ```

4. **验证访问**
   ```bash
   curl -s -o /dev/null -w "%{http_code}" http://localhost:{端口}/
   ```

### 端口选择建议
- 常用端口：8080、8888、9000
- 检查端口占用：`netstat -tlnp | grep ":{端口}"`
- 避免使用已被占用的端口（如3000、3001、8899等）

### GitHub仓库创建
```bash
# 1. 初始化Git仓库
cd /home/ubuntu/{项目名}
git init
git add .
git commit -m "Initial commit"

# 2. 创建GitHub仓库（使用GitHub API）
curl -H "Authorization: token {TOKEN}" -d '{"name":"{仓库名}","description":"{描述}","private":false}' https://api.github.com/user/repos

# 3. 添加远程仓库并推送
git remote add origin https://github.com/{用户}/{仓库名}.git
git push -u origin master
```

### 安全组配置提醒
- 腾讯云服务器需要在安全组中开放相应端口
- 默认可能只开放80、443端口
- 如需访问自定义端口（如8080），需在安全组中添加入站规则

### 访问地址格式
- 内网访问：`http://localhost:{端口}`
- 外网访问：`http://{服务器IP}:{端口}`（如：`http://43.139.81.132:8080`）
